# Laboratorio de Modelación y Simulación

Integrantes: Benjamín Hernández y María José Fuentes.

Se necesita MATLAB R2025a o posterior con Control System Toolbox. También se puede usar MATLAB Online.

Abrir la carpeta `modelos` en MATLAB y ejecutar cada pregunta desde la ventana de comandos:

```matlab
run('matlab/pregunta1.m')
run('matlab/pregunta2.m')
```

Los gráficos y los datos se guardan en la carpeta `figuras_matlab`.
